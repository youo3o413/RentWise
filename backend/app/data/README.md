## 可比較的需求

- 低預算：總預算 11,000 元、可接受無對外窗，與 25,000 元預算比較。
- 寵物及開伙：總預算 25,000 元、通勤 40 分鐘、無電梯樓層上限 6，勾選可養寵物及可開伙，再與未勾選比較。
- 設備：需要電梯、對外窗或租補，觀察必要條件與待確認項目。
- 偏好：提高安靜程度或房屋條件權重，觀察幹道與巷內房源差異。

預設目的地為政治大學，房源仍固定是這 18 筆台大周邊假資料。目的地不是台大時，後端會清除台大示範通勤時間，再交由既有地圖工具重新查詢通勤。選擇台大時，示範推薦在未設定 OpenAI 金鑰的情況下不需要外部網路；開地圖仍可能載入地圖圖磚。

伺服器預設 `LIVE_LISTING_SOURCES_ENABLED=false`，即使舊請求使用 `multi` 或 `591`，也改讀示範資料，不執行爬蟲。

## 房源照片與推薦數量

18 張照片由使用者提供的 Google Drive 資料夾（1lob0gZVPqLNI78xiMsn9k-5ZOKmNylis）取得清單，與本機附件名稱及大小核對後，轉成最長邊 1280px 的 JPEG 存在 `listing_photos/`。照片隨機分配一次，對應關係保存在 JSON 的 `image_url` / `image_urls`，不會每次請求重新抽選。圖片只是配圖，隨機分配不保證符合文字房況。

前端與 API 的顯示文案使用中性房源名稱，資料仍為上述虛構情境，`listing_text_source` 與 `nearby_data_source` 保留 `mock`。全部 18 筆都會參與 Agent 分析與評分，排序後只回傳前 10 筆；回饋重新排名仍使用全部候選。OpenAI 啟用時，Property Agent 可讀取內建圖片判讀窗戶與空間。
